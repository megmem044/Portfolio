# Third-party software

AnswerTrust uses Streamlit (Apache-2.0), pytest (MIT), and
sentence-transformers (Apache-2.0) as declared in `requirements.txt`. The
optional `all-MiniLM-L6-v2` model is downloaded locally from Hugging Face and
is distributed under Apache-2.0. Refer to each installed package or model
distribution for its full license text and transitive dependency notices.
